## 从公开采购信息，看见真实 AI 需求

关于 AI 的讨论很多，但采购信息回答的是更具体的问题：**哪些单位正在采购、采购什么能力、处于哪个采购阶段，以及公开了多少预算或中标金额。**

AI 招投标信息网把分散的人工智能招标公告、政府采购、采购意向、中标公告和成交结果，整理为按日期浏览的信息流。你可以直接查找项目，不必在大量无关公告之间反复翻页。

> [!TIP]
> 招标公告代表项目正在进入采购流程，采购意向代表潜在预算方向，中标或成交结果则更接近已经发生的购买。分开看这三类信息，比笼统判断“AI 很热门”更有价值。

## 你可以用它做什么

| 你关心的问题 | 在网站里怎么看 |
| --- | --- |
| 现在有哪些 AI 项目正在采购？ | 选择日期，查看当天的招标公告和政府采购信息，并按发布时间从近到远浏览 |
| 哪些 AI 能力正在形成付费需求？ | 搜索标题、正文摘要或采购单位，观察反复出现的产品模块和交付内容 |
| 市场愿意为这些项目花多少钱？ | 关注公告披露的预算金额、中标金额或成交金额 |
| 哪些单位和地区正在投入 AI？ | 结合采购单位、地区和公告类型判断需求来源 |
| 一个需求是意向、招标，还是已经成交？ | 通过采购意向、招标公告、中标公告等类型区分项目阶段 |
| 哪些机会适合继续跟踪？ | 打开详情查看正文摘要、项目编号和采购单位，复制标题后继续检索原始公告 |

## 你会看到哪些 AI 项目

公开采购中的 AI 并不只有“大模型平台”。信息流中还会出现更具体的应用与交付方向，例如：

- AI 模型账号、API 与算力服务
- 智能体、知识库与智能问答
- AI 教学、作业批改、学情分析与智慧课程
- 医疗 AI、视觉识别与行业辅助决策
- 数字人、虚拟主播与内容自动生产
- 数据治理、模型评测与私有化部署
- GPU 服务器、算力平台与相关软硬件采购

这些项目名称和采购正文，能够帮助产品团队、服务商和独立开发者从真实采购语境中理解需求，而不是只依赖行业概念。

## 核心功能

- **按日期浏览**：快速切换日期，查看指定日期发布的 AI 招投标信息
- **时间顺序清晰**：当天公告按发布时间从近到远排列
- **站内搜索**：搜索项目标题、正文摘要和采购单位
- **类型筛选**：区分招标公告、采购意向、中标公告、中标结果等信息
- **金额筛选**：只查看披露预算金额或中标金额的项目
- **信息详情**：查看正文摘要、采购单位、代理机构、地区和项目编号
- **标题复制**：在详情中一键复制完整标题，便于继续核验和检索
- **独立详情页**：每条公告拥有可访问、可分享的独立页面

## 每条信息包含什么

| 信息字段 | 用途 |
| --- | --- |
| 项目标题 | 识别采购标的与应用场景 |
| 发布日期与时间 | 判断信息时效，按时间跟踪新增项目 |
| 公告类型 | 区分采购意向、招标、竞争性采购、中标或成交阶段 |
| 地区 | 了解项目发布区域 |
| 采购单位 | 判断需求方及其所属行业 |
| 代理机构 | 了解项目组织与执行主体（如有） |
| 项目编号 | 用于跨平台核验同一项目（如有） |
| 正文摘要 | 快速了解采购内容、规格和交付要求 |
| 预算或中标金额 | 评估采购规模；仅在公告披露时展示 |

## 如何使用

1. 打开 [AI 招投标信息网](https://ai-tender-radar.vercel.app)，选择想查看的日期。
2. 使用搜索、公告类型和金额筛选，缩小到与你相关的项目。
3. 打开详情阅读正文摘要；需要进一步核验时，复制完整标题并检索原始公告。

## 仓库内容

- `public/`：网站页面、信息索引与公告详情页

- `docs/preview.png`：当前网站界面预览

## 数据说明

本站是 AI 招投标公开信息的整理与浏览入口，不是招标代理机构或政府采购官方网站。信息可能因原始页面更新、字段缺失或文本解析而不完整；参与投标、报价、采购或商业决策前，请以采购单位和官方发布渠道的原始公告为准。

未披露金额的项目不会显示金额字段。采购意向、招标公告与中标结果代表不同采购阶段，不应被视为同等强度的成交证据。
