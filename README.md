# AI 招投标信息流

一个按日期浏览的 AI 招投标公开信息流网站。

在线访问：<https://ai-tender-radar.vercel.app>

![AI 招投标信息流预览](docs/preview.png)

## 网站展示

- 按日期选择和浏览 AI 招投标信息
- 当天信息按发布时间从近到远排列
- 展示标题、正文摘要、公告类型、地区、采购单位、项目编号
- 展示预算金额或中标金额（如有）
- 支持搜索标题、正文摘要和采购单位
- 支持按公告类型和金额信息筛选
- 点击记录查看完整信息

网站代码和公开信息数据同步在本仓库中。
