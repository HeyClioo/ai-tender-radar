# AI 招投标信息网｜全国人工智能招标公告、政府采购与中标结果

按日期查询全国 AI 及人工智能招投标信息，包括招标公告、政府采购、采购意向、中标公告和中标结果；可查看采购单位、项目预算及中标金额。

在线访问：<https://ai-tender-radar.vercel.app>

![AI 招投标信息网预览](docs/preview.png)

## 网站展示

- 按日期查询和浏览全国 AI、人工智能招投标信息
- 当天信息按发布时间从近到远排列
- 展示 AI 招标公告、政府采购、采购意向、中标公告和中标结果
- 展示标题、正文摘要、公告类型、地区、采购单位、项目编号
- 展示预算金额或中标金额（如有）
- 支持搜索标题、正文摘要和采购单位
- 支持按公告类型和金额信息筛选
- 每条公告提供独立详情页

网站代码和公开信息数据同步在本仓库中。
